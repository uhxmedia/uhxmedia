# UHX MEDIA — Unified Human Experience

Premium responsive agency website for UHX MEDIA.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Optional Python local server

## Run in VS Code
Open this folder in VS Code and use Live Server on `index.html`.

## Run with Python
```bash
python3 server.py
```
Then open http://localhost:8000

## GitHub
```bash
git init
git add .
git commit -m "Initial UHX MEDIA website"
git branch -M main
git remote add origin YOUR_REPOSITORY_URL
git push -u origin main
```

## Before launch
1. Formspree is connected to `https://formspree.io/f/xppwkjgq`.
2. Replace `https://uhxmedia.com/` with the final domain if different.
3. Add final favicon/social preview artwork in `assets/`.
4. Test the enquiry form, mobile layout and all links.
